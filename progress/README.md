# Progresso personale

`learner-profile.example.json` illustra il formato senza attribuire mastery. Il profilo reale `learner-profile.json` è ignorato da Git e non viene creato. Se in futuro lo crei, conserva localmente solo dati minimali e artifact sanitizzati. Non inserire dati di minori, credenziali o conversazioni reali.

Per ogni assessment conserva task, artifact, rubric, data e valutazione distinta dall'autovalutazione. Il completamento di una lettura non aggiorna il livello. I validator del repository controllano l'example, senza leggere il profilo privato.
