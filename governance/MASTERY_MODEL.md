# Coverage e mastery

| Coverage della fonte | Significato |
| --- | --- |
| C0 | Nessuna evidenza curricolare |
| C1 | Citato o spiegato soltanto concettualmente |
| C2 | Insegnato con esempi o esercizi guidati |
| C3 | Praticato in laboratorio o progetto sostanziale |
| C4 | Validato in un sistema autentico mantenuto |

| Mastery personale | Dimostrazione |
| --- | --- |
| M0 — Recognize | Riconosce il termine e sa localizzarlo |
| M1 — Explain | Spiega scopo, vocabolario, modello mentale e failure mode |
| M2 — Apply with guidance | Completa un task delimitato con checklist e verifica |
| M3 — Work independently | Implementa, testa, diagnostica e recupera autonomamente in ambiente pulito |
| M4 — Maintain and design | Modifica codice non familiare e cross-cutting, progetta guardrail e reviewa altri |

M2 è il target dei primi lab; il requisito professionale della skill può essere M3 o M4. Un lab guidato non certifica M3. Il profilo example usa `learner_mastery: null` (non valutato), non M0 attribuito automaticamente. Un assessment futuro deve registrare skill, artifact, data, revisore, rubric, pass/fail e livello dimostrato. Autovalutazione e valutazione restano campi diversi. Nessuna promozione automatica da course status o copertura SSRI.
