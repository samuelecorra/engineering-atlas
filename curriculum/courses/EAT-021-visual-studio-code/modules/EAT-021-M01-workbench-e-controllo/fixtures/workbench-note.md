# Appunto del workbench

Questo documento sintetico serve a provare ricerca, spostamento dei file e ritorno a capo visivo in una copia isolata del lab. La parola da cercare è osservazione.

Questa riga volutamente lunga contiene un’osservazione sul fatto che la visualizzazione di un documento può cambiare senza che il contenuto del documento venga riscritto: controlla il diff per distinguere le due situazioni.
