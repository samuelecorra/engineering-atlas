# Visual Studio Code: ambiente professionale e lavoro con agenti

Programma canonico in [course.json](course.json). Il corso nasce dalla priorità espressa l’8 settembre 2026: controllo dell’IDE, configurazione consapevole e uso verificabile di Copilot, Codex e Claude Code.

Il primo modulo è draft: due unità, quattro lezioni, lab e assessment. Gli altri undici moduli sono planned. La guida alle estensioni del profilo principale attende l’export; non vengono inventati ID, impostazioni o abbonamenti personali.

Il corso rinforza skill già possedute da EAT-001 e EAT-019 senza duplicarne ownership o attribuire nuova coverage SSRI. L’ordine di lettura introduttivo parte da qui; gli argomenti avanzati rimandano ai corsi Git, toolchain e infrastruttura.

La completezza si verifica contro il programma e le prove, non attraverso una dichiarazione “100%”. Fonti e versioni sono riportate nelle singole lezioni. Leggere non equivale a superare l’assessment.
